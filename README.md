# WB Analiz Bot

Телеграм-бот для продавцов Wildberries. Анализ остатков, рекомендации по ценам, ежедневные отчёты.

## Возможности

- **Мультимагазин** — подключение нескольких магазинов WB по API-токену
- **Excel-отчёты** — товары с группировкой по скорости продаж (A/B/C), остаток в днях, рекомендации по повышению цены
- **Ежедневная рассылка** — автоматическая отправка отчётов подписчикам в заданное время
- **Гибкие настройки** — время рассылки, пороги групп, период анализа — всё через меню бота
- **Защита** — опциональный пароль, обфускация токенов, маскировка в логах

## Быстрый старт

1. Создать `.env` файл:
   ```bash
   cp .env.example .env
   ```

2. Заполнить обязательную переменную:
   ```
   TELEGRAM_TOKEN=токен_от_BotFather
   ```

3. Запустить:
   ```bash
   ./start.sh
   ```

Бот запустится в Docker-контейнере. Данные сохраняются между перезапусками.

## Работа с ботом

### Команды
- `/start` — запуск бота (авторизация если задан пароль)
- `/menu` — главное меню

### Главное меню
- **📊 Анализ остатков** — выбор магазина → последний отчёт или генерация нового
- **⚙️ Настройки** — магазины, время рассылки, параметры расчёта, подписка

### Управление магазинами
Добавление: отправьте API-токен WB → бот проверит его и подтянет название.
Можно задать торговое название (бренд) для удобного отображения.
Токен получается в личном кабинете WB → Настройки → Доступ к API.

### Отчёты
Excel-файл с товарами, где для каждого:
- Артикул, название, категория
- Остаток на складе / в пути от клиента
- Заказы за 7 / 14 / 30 дней
- Средние продажи в день и остаток в днях
- Рекомендация по повышению цены (если остаток < порога)

Товары разделены на группы по скорости продаж:
- 🟢 **Группа A** — (≥4 шт/день)
- 🟠 **Группа B** — (≥0.5 шт/день)
- 🟣 **Группа C** — (<0.5 шт/день)

### Подписка на рассылку
Подписаться/отписаться — через Настройки. Подписчики получают отчёты по всем магазинам ежедневно (по умолчанию 09:00 МСК).

## Управление контейнером

```bash
# Логи
docker-compose logs -f

# Остановить
docker-compose down

# Перезапустить
docker-compose restart
```
